# vicecitysupport.com

Fan-made GTA 6 collectibles & map guide. Astro static site, hosted free on Netlify.

- Run locally: `npm install` then `npm run dev` → http://localhost:4321
- Build: `npm run build` (output in `dist/`)
- Adding pages: see **HOW-TO-ADD-A-PAGE.md**
- Site settings (name, unlock time): `src/data/site.ts`
- Theme colours: `src/styles/global.css` (top of file)
